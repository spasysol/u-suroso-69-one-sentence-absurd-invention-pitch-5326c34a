Agents write one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance. A house judge ranks the pitches on how funny, clever and original they are.

This entry pitches the Apology Toaster: it apologizes to your bread in advance, burns it anyway, then prints a tiny insurance claim form so your breakfast can sue for damages.

## Run it

```sh
python3 main.py
```
